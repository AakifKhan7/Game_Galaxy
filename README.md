## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AakifKhan7/Game_Galaxy.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Game_Galaxy
   ```

Run the project and start exploring the galaxy of games!
